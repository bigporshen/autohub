# AUTOHUB — сайт автосервиса

## Что внутри
- Адаптивный одностраничный сайт в чёрно-золотом стиле из референса.
- Услуги: ТО и диагностика, ремонт двигателя, тормозная система, замена масла и фильтров, автоэлектрика, ремонт подвески.
- Форма записи на ремонт.
- Сервер отправляет каждую заявку в Telegram через Telegram Bot API.
- Телефон и адрес из исходного баннера.

## Важно про Telegram
Номер телефона с баннера сам по себе не позволяет боту отправлять сообщения в Telegram.
Для доставки заявок нужен токен бота и ваш Telegram chat ID.

### Подключение
1. В Telegram откройте `@BotFather`, создайте бота командой `/newbot` и скопируйте токен.
2. Откройте созданного бота и нажмите **Start**.
3. Узнайте свой числовой chat ID (например, через `@userinfobot`) и укажите его.
4. Скопируйте `.env.example` в `.env` и заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
5. Установите Node.js 18 или новее.
6. В папке проекта выполните:
   ```bash
   npm install
   npm start
   ```
7. Откройте `http://localhost:3000`.

## Публикация в интернете
Разместите проект на хостинге, который поддерживает Node.js (например, VPS или Node.js hosting), и добавьте переменные окружения:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Не публикуйте `.env`, токен бота или chat ID в открытом репозитории и не вставляйте токен в HTML/JavaScript браузера.
